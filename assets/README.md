# Recursos visuais

- `catalog.json`: metadados e miniaturas das 32 molduras. Campos `asset` apontam para PNGs em `frames/`, carregados sob demanda.
- `symbols.json`: os 80 símbolos incorporados, usados pelo renderizador e pela barra de mana.
- `fonts/`: Beleren e Magic the Gathering clássica. Declarações em `styles/fonts.css`.

São os mesmos recursos já utilizados pelo Arcana Studio. Dados e símbolos de edições: Scryfall. Recursos de molduras: referência pública MTGCardBuilder. Desenhos e elementos de Magic pertencem à Wizards of the Coast e aos respectivos criadores. Beleren e Magic the Gathering: Wizards of the Coast. Arquivos de referência anteriormente obtidos das distribuições de fan content Saeris/Proxyshop. O projeto não reivindica a autoria desses recursos.

A fonte Plantin não é redistribuída. Os textos usam Times New Roman/serif do sistema; o editor permite carregar uma fonte própria autorizada.
