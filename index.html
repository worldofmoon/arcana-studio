Comece com uma carta

Pesquise para importar os dados ou edite os campos na aba Texto para criar uma carta própria.

Digite pelo menos 2 letras.

A importação traz textos, mana, edição e a ilustração. A moldura é construída pelo editor: a imagem original da carta não é recortada.

Escolha a moldura

Molduras próprias, inspiradas na estrutura de Magic. Todas são desenhadas sobre a arte, com bordas contínuas.

Moldura própria com transparência

Sua moldura é aplicada sobre o fundo e antes dos textos. Se a imagem for opaca, ela cobrirá a arte.

Edite os textos

Símbolos como {T}, {C}, {W/U} e {W/P} são desenhados como ícones no PNG. O texto reduz automaticamente quando necessário.
